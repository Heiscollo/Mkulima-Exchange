# Mkulima Exchange 🌾

Mkulima Exchange is a mobile application designed to connect Kenyan farmers directly with consumers, eliminating the need for middlemen. The platform aims to promote fair pricing, increase farmers' profits, and allow consumers to access fresh farm produce at affordable prices.

## 📱 Project Overview

In many agricultural markets in Kenya, middlemen dominate the supply chain, often reducing the profits farmers receive for their produce. Mkulima Exchange solves this problem by creating a digital marketplace where farmers can list their products and consumers can buy directly from them.

The application is being developed using Flutter to provide a modern, scalable, and user-friendly mobile experience.

## 🎯 Objectives

- Connect farmers directly to consumers
- Eliminate unnecessary middlemen
- Promote fair pricing of agricultural products
- Provide consumers with fresh farm produce
- Digitize the agricultural marketplace in Kenya

## 🚀 Features

- User authentication (Login & Sign Up)
- Farmer product listings
- Product browsing for consumers
- Order placement
- Search and filter for farm products
- User profiles
- Simple and intuitive UI

## 🛠️ Technologies Used

- **Flutter** – Cross-platform mobile development
- **Dart** – Programming language for Flutter
- **Firebase** (planned) – Authentication and backend services
- **Git & GitHub** – Version control and collaboration
